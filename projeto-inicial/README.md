# Notificações Multicanal no Laravel — projeto inicial

Ponto de partida executável com Laravel, Database, Mail, Slack, Web Push, filas, migrations e artefatos-base instalados. O fluxo da apresentação será implementado seguindo o `TESTING.md`.

```bash
composer install
npm install
php artisan migrate:fresh --seed
npm run build
php artisan test --compact
php artisan serve
```

Use PHP 8.3+, Composer 2 e Node.js 22.12+ ou 20.19+.
